# Pressure Ripple / Basınç dalgası

## Türkçe

[Canlı aracı aç](https://omerbek.github.io/pressure-ripple/).

İstasyonun merkezinden yayılan bir uyarı efekti oluştur.

## Çalıştırma

`index.html` dosyasını bir tarayıcıda aç. Oynat düğmesini ve zaman çizelgesini kullanarak sekiz saniyelik sahneyi incele. HTML ve Canvas 2D ile çevrimdışı çalışır.


## Sahne ayarları

- Halka sayısı
- Yayılma süresi (s)
- Yatay yarıçap

Sekiz saniyelik zaman çizelgesinden bir kare seçip **PNG indir** ile 720 × 405 piksel dışa aktarabilirsin.

## English

Adjust the number, radius and speed of expanding pressure rings.

Open [the live tool](https://omerbek.github.io/pressure-ripple/) or open `index.html` in a browser. Switch between Turkish and English in the page header. Use the timeline to select a frame and **Download PNG** to save it at 720 × 405 pixels.
